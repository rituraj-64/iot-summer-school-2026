# IoT Week 3

## Overview

This folder contains the Week 3 assignments completed during the **IoT Summer School 2026**. The projects focus on environmental monitoring, multiple sensor integration, motor control, automation, and smart embedded system applications using Arduino.

---

## Projects Included

### Environmental Monitoring
https://wokwi.com/projects/468441225781705729

* Reads temperature and humidity using a DHT sensor.
* Displays readings in CSV format and indicates environmental status using LEDs.

### Parking Sensor
https://wokwi.com/projects/468441343245304833

* Ultrasonic-based parking assistance system.
* Uses LEDs and a buzzer to indicate the distance from nearby objects.

### Multi-Sensor Logger
https://wokwi.com/projects/468441378805678081

* Collects data from multiple sensors including a DHT sensor, LDR, and ultrasonic sensor.
* Displays structured sensor logs through the Serial Monitor.

### Servo Control
https://www.tinkercad.com/things/7gyStqv5tqT-servo-motor-sweep?sharecode=A-0JzaNqEo2-itlMNAI3xn3ZXAlHaADIpK6wZ6IkiEo

* Controls an SG90 servo motor using a potentiometer.
* Includes a push button to perform an automatic sweep operation.

### Potentiometer Speed Control
https://www.tinkercad.com/things/cQwmxBud23W-potentiometer-speed-control?sharecode=5ZQMfzL_NfQd_VAiUvg-EpjG_Tvj52IA00ghCBnXgIo

* Controls DC motor speed using a potentiometer and motor driver.
* Supports start/stop and direction control.

### Relay AC Simulation
https://wokwi.com/projects/468441541296209921

* Simulates automatic AC control using a relay module based on temperature readings.
* Includes manual override functionality.

### Password Lock
https://www.tinkercad.com/things/2jLqHJRFS70-password-lock?sharecode=oJ75jCrTSI84zsEgoB93WMwxtXrpo-4tA-Q_CmgMHYM

* Password-protected access system using a 4×4 keypad, 16×2 LCD, LEDs, and buzzer.

### Smart Street Light
https://www.tinkercad.com/things/iUMWnN7ZPa5-smart-street-light?sharecode=R5lvUFjr0l1T3rANZzkBMuhQVyzthTZC9YKclfpxz48

* Automatic street lighting system using an LDR to detect ambient light conditions.
