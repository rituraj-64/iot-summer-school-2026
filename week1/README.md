# IoT Week 1

## Overview

This folder contains the Week 1 assignments completed during the **IoT Summer School 2026**. The exercises focus on learning Arduino programming fundamentals, digital input/output, LED control basic embedded system concepts.

---

## Projects Included

### LED Blink
https://www.tinkercad.com/things/8DFUxrUPBma-ledblinker10?sharecode=a5t442LJ0fXUt3fQURKBUknLoruCg0Tkg5yAGgSUcE0

* Basic Arduino program to blink an LED.
* Demonstrates digital output and timing using `delay()`.

### Pushbutton LED
https://www.tinkercad.com/things/aNAVocfeA2U-push-button-led?sharecode=NAsRDjjCjUzttJEpiNXeEHiAL2OpYCp0SrLV4uCE4uY

* Controls an LED using a push button.
* Demonstrates digital input and button state detection.

### LED Fade Array
https://www.tinkercad.com/things/d8iniVUGe5j-led-fade-array?sharecode=6ks9z7drGCOXBjS-EC3xroz2UF9_5pOifw5AqcUqyHI

* Fades multiple LEDs using PWM and arrays.
* Demonstrates analog output and array-based programming.

### LED 4×4 Matrix
https://www.tinkercad.com/things/ecLokdGEsWx-4x4-using-matrix?sharecode=MJSr7IUqEdbnUhgmODsHOwWHcNt5QLNLfOCXE_gCAjo

* Controls a 4×4 LED matrix using row and column multiplexing.
* Demonstrates matrix scanning and efficient pin usage.

### LED 4×4 Array
https://www.tinkercad.com/things/hIFxTowgGay-4x4-using-array?sharecode=pPwP_kuhmdns6Z_tmJd66orWlj6mFjIjpWTUJXkTpXQ

* Controls LEDs using array indexing and loops.
* Demonstrates structured programming with arrays.

### Seven Segment Dice
https://www.tinkercad.com/things/7bleRd83etx-dice?sharecode=sHC1BPzOBRHJ90w9otKm5jNwmktyV9k0cdkfWgr1c20

* Simulates a digital dice using a seven-segment display.
* Displays random numbers from 1 to 6.

### Reaction Time Game
https://www.tinkercad.com/things/dqiL3e72pWz-reaction-time-game?sharecode=6ayfaIoWxp8070V1jOK1ohIVhbvUzYQ-wfK7nht_OtU

* Measures user reaction time using LEDs and a push button.
* Demonstrates timing, random delays, and user interaction.
