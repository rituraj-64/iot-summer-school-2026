# IoT Week 2

## Overview

This folder contains the Week 2 assignments completed during the **IoT Summer School 2026**. The projects focus on Arduino communication protocols, PWM control, serial communication, automation, and mini embedded system applications.

---

## Projects Included

### Traffic Light Controller
https://www.tinkercad.com/things/dt57upmj5H9-traffic-light?sharecode=Lo5feR9iaAdC0YGlRLHckKyzdxmTe5LRssfjkGRhLQw

* Simulates a traffic light using LEDs with a pedestrian button override.

### Digital Piano
https://www.tinkercad.com/things/bWWskKHjrw5-digital-piano?sharecode=vmyoRVGX25s9OvqVBp5kOVfYS0ejrRDLcsMlRzjAVrE

* Supports Major/Minor mode switching.

### Serial Command Interface
https://www.tinkercad.com/things/i7anwHcCFcV-serial-command-interface?sharecode=lIgQbBk1Y3fAAzKai5oTYgpqqaOXkZB-czZVC4LmWPU

### PWM Fading Night Light
https://www.tinkercad.com/things/keq8zvcWao6-pwm-fading-night-light?sharecode=I_YABz1WQQKjgUi3qKs6Vp7bkR0OK3ywHawZ1DUkmZI

### Vending Machine
https://www.tinkercad.com/things/1doZOSI9VuU-vending-machine?sharecode=BH3we6ZOgoR2nc4tRKQjJVg_MbjY9svvY2SeEG7Sf7o
